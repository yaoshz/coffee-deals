1. **星巴克週一／週二官方活動收斂**：改成按 `monday`、`tuesday` 分組融合所有官方卡與舊新聞摘要，不再讓單一字典中的最後一筆覆蓋其他紀錄。官方活動頁存在時，優先保留官方網址、活動期間、官方主標與詳細說明；同時合併所有來源網址。星沁爽等獨立商品不會被併入常態卡。

4. **過濾媒體總覽標題**：排除「11 款咖啡、茶飲優惠組合」「最高現省 500 元」等沒有獨立促銷條件的宣傳標題。
5. **延續 v6.9 架構**：後端負責排序與去重；前端維持繁體中文、英文、泰文切換，並按 `deals.json` 原順序顯示。

## GitHub 部署

將本套件中的下列檔案上傳並覆蓋 GitHub 專案同名檔案：

- `scraper.py`
- `deals.json`
- `index.html`
- `requirements.txt`
- `test_scraper_dedup.py`

保留既有的 `.github/workflows/update-coffee-deals.yml`，再手動執行 GitHub Actions。建議先執行測試：

```bash
python -m unittest -v
```

目前有 81 項離線回歸測試，包含星巴克官方卡收斂、空商品集合去重、LINE 禮物泛稱與具體品項合併、跨店優惠防止誤合併、新聞總覽標題過濾及快照冪等性。

資料來源和日期可能因媒體網頁結構變化而不完整；效期、門市、付款方式與商品限制仍應以來源原文及店家公告為準。
